# Project 1: Personal Expenses Analysis



### Overview

This project demonstrates an early-stage prototype for analyzing personal expenses and identifying spending patterns.  

The goal was to explore simple visualization and dashboarding techniques using synthetic expense data.



### Key Objectives

- Build a simple framework for categorizing and visualizing expenses.

- Experiment with Pandas and Matplotlib for quick data summaries.

- Prototype a dashboard layout for potential future use in personal finance analytics.



### Tools \& Technologies

- Python (Pandas, Matplotlib)

- Jupyter Notebook



### Notes

This was an introductory exercise — no real dataset was used. Later projects build on this foundation with real-world data and machine learning.
